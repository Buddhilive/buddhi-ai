# Style Recipe: Minimal Editorial (Warmth & Typographic Contrast)

## Aesthetic Identity
Understated luxury, editorial restraint, and museum-grade negative space. Inspired by Aesop, Kinfolk, and modern architectural journals.

## Design Tokens
- **Backgrounds**: `#fbf9f5` (Warm Cream), `#f3ede2` (Soft Sand), `#201e1c` (Dark Charcoal in dark mode)
- **Borders**: `#e4dcce` (Natural Linen Divider)
- **Text**: `#1f1c19` (Deep Umber), `#5c564f` (Muted Clay)
- **Accents**: `#945d3c` (Terracotta), `#2d4b43` (Cypress Green)
- **Typography**: Serif for headlines (e.g. Playfair Display, Newsreader, Georgia), Clean Grotesk Sans for captions/body (Inter, Helvetica Neue).
- **Border Radius**: Sharp or minimal (0px to 4px).
- **Spacing**: Generous whitespace (padding 64px - 120px between sections).

## Signature Moves
- Large, confident serif headlines with delicate hairline dividers (`<hr class="border-stone-300 my-8" />`).
- High-contrast column grids with asymmetrical image placements.
- Numbered section markers (`01 // OVERVIEW`, `02 // SPECIFICATION`).

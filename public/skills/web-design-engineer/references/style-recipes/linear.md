# Style Recipe: Linear Dark (Precision & High Craft)

## Aesthetic Identity
Dark, technical, razor-sharp, and extremely disciplined. Inspired by Linear and modern developer tools.

## Design Tokens
- **Backgrounds**: `#08090a` (Deep Void), `#101216` (Card Surface), `#181b20` (Hover Surface)
- **Borders**: `rgba(255, 255, 255, 0.08)` (Subtle Dividers), `rgba(255, 255, 255, 0.16)` (Interactive Border)
- **Accents**: `#5e6ad2` (Electric Indigo), `#46a758` (Status Green), `#f76808` (Alert Orange)
- **Typography**: Inter / SF Pro Display. Title font-weight: 500-600, tight letter-spacing (`tracking-tight` / `-0.02em`).
- **Shadows**: `0 0 0 1px rgba(255,255,255,0.08), 0 8px 24px -4px rgba(0,0,0,0.8)`
- **Border Radius**: 6px for buttons/inputs, 10px for cards/modals.

## Signature Moves
- Very thin 1px hairline borders (`border-white/10`).
- Subtle linear gradient badges with glowing hover edges.
- Monochrome high-density data tables and keyboard shortcut indicators (`<kbd class="px-1.5 py-0.5 rounded border border-white/10 bg-white/5 text-xs text-zinc-400">⌘K</kbd>`).

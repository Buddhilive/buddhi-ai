# Anti-Patterns Blocklist (Design Clichés to Avoid)

1. **The AI Purple/Violet Gradient Syndrome**:
   - Never render a dark background with an amorphous centered purple/magenta radial blur blob.
   - Replace with intentional accent colors (electric teal, amber, crisp white, deep emerald).

2. **The Generic 3-Card Feature Row**:
   - Don't just make three identical grey boxes with identical rounded icon circles in the center.
   - Use asymmetrical layout: One large feature showcase card (2 cols) + two compact metric cards (1 col each).

3. **Floating Without Hierarchy**:
   - Never output text without clear contrast between title, subtitle, and body.
   - Never use grey body text on light grey backgrounds.

4. **Fake Image Placeholders**:
   - Never output `[Image goes here]` or `<div class="bg-gray-300 h-64"></div>`.
   - Use beautiful SVG illustrations, SVG patterns, or real Unsplash images.
